# ⚡ SertifikatKilat

**Bulk Certificate Generator (Offline & Privacy-First)**

SertifikatKilat adalah aplikasi desktop untuk membuat sertifikat dalam jumlah besar secara cepat menggunakan template PowerPoint dan data Excel.
Semua proses berjalan secara lokal tanpa mengunggah data ke layanan online.

---

## 🚀 Features

* ✔ Generate sertifikat massal dari Excel
* ✔ Template berbasis PowerPoint (fleksibel & mudah digunakan)
* ✔ Output PDF siap cetak
* ✔ Auto merge PDF
* ✔ Validasi otomatis antara parameter PPT dan header Excel
* ✔ Offline (no internet required)
* ✔ Privacy-first (data tidak keluar dari device)

---

## 🎯 Use Case

SertifikatKilat cocok untuk:

* Seminar & Workshop
* Training & HR internal
* Event & komunitas
* Kegiatan edukasi / pelatihan

---

## 🧠 Cara Kerja

Workflow sederhana:

```
Excel (data peserta)
        ↓
PowerPoint Template (<<parameter>>)
        ↓
Generate Sertifikat
        ↓
PDF Output + Merge
```

## 📝 Format Template

Gunakan format parameter di PowerPoint:

```
<<Nama Peserta>>
<<Tanggal>>
<<Pelatihan>>
```

Header Excel harus sama persis:

| Nama Peserta | Tanggal | Pelatihan |
| ------------ | ------- | --------- |
